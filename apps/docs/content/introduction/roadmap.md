These are intentions, not commitments, and nothing on this page exists yet.

## Before a public release

- Publish the packages to a registry.
- Run the browser tests in CI, on Linux as well as Windows.
- Test in Safari itself, and on real phones.
- Gather feedback on the language, while it can still change.

## Language

- Arbitrary variants, for one-off selectors and media queries.
- An `important` modifier.
- Container query variants, and a `dark` variant in the core.
- Composable `ring` and `shadow`, which currently both set `box-shadow`.

## Tooling

- An editor extension: autocomplete, hover to see the CSS, and inline diagnostics.
- More integrations, such as webpack and Rspack.

## Ecosystem

- Published plugins for typography and animation.
- A migration guide for people coming from other utility frameworks.

Suggestions are welcome once the repository is public. See [Contributing](/docs/community/contributing).
