# @croff/cli

The `croff` command: `init`, `dev`, `build` and `check`. Every command has `--help`.

```bash
croff init
croff dev --output dist/croff.css
croff build --input src/croff.css --output dist/croff.css
croff check --strict
```

Part of [CROFF](../../README.md), version 0.1.0 (pre-release, not published yet).
